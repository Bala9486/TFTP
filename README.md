# TFTP Client-Server Implementation

## Project Overview

Developed a Trivial File Transfer Protocol (TFTP) application using C programming and socket programming in Linux. The project demonstrates file transfer between a client and server over a network using UDP communication.

## Technologies Used

* Programming Language: C
* Operating System: Linux (Ubuntu)
* Networking: Socket Programming
* Protocol: UDP
* Tools: GCC, Linux Terminal

## Features

* Client-Server Communication
* File Upload and Download
* UDP-Based Data Transfer
* Packet Handling
* Error Handling

## Concepts Learned

* Socket Programming
* UDP Communication
* Client-Server Architecture
* File Handling in C
* Network Protocol Implementation

## How to Compile

```bash
gcc *.c -o tftp
```

## How to Run

Run the server and client separately according to the project implementation.
